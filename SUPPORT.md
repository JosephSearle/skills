# Support

This repository's issue tracker is for bugs and feature requests, not general usage questions.
There's no separate community channel (no Discussions, chat, mailing list, or forum) — the issue
tracker is the only place to ask.

## Got a question about using a skill or the site?

Open a [GitHub issue](https://github.com/JosephSearle/skills/issues) and label it as a question.
Before you do, check whether it's already answered:

- The skill's own `SKILL.md` under `catalog/<skill-name>/` — that's the source of truth for what
  a skill does and how to trigger it.
- The [README](README.md), for how the catalog and site fit together, and how to use or download
  a skill.

## Found a bug or want a new skill?

Open a [GitHub issue](https://github.com/JosephSearle/skills/issues). See
[CONTRIBUTING.md](CONTRIBUTING.md) for what to include in a bug report or enhancement proposal,
and for the pull request process if you want to submit a fix yourself.

## Found a security vulnerability?

Don't open a public issue. See [SECURITY.md](SECURITY.md) for how to report it privately.

## Conduct issue?

See the [Code of Conduct](CODE_OF_CONDUCT.md).
