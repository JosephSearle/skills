# Intent: Remind me before a task is due

## Problem
Tasks with due dates slip because nothing tells the user a due date is coming up. Users only notice
when they happen to open the list.

## Proposed outcome
Users get a reminder the day before a task is due, without having to open Tasklist.

## Affected users and systems
Any user who sets due dates. Touches the tasks store and needs some way to deliver a message
outside the app.

## Constraints
- No new paid services.

## Open questions
- Email, or something else?
- Can users opt out?
